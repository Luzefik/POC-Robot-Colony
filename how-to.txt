How to run this code

1. Go to btstack/port/esp32

2. Run 
./integrate_btstack.py

3. Go to the root dir and do
idf.py set-target esp32
(make sure enviroment target is also set to esp32)
( $env:IDF_TARGET = "esp32" )

Run it!
4.idf.py build flash monitor
After this you'll be able to connect ps4 controller to the board (hold ps + share)
